# Topic Candidates

Both candidates are proposals. Neither is a locked thesis topic.

## A — Control-Aware Predictive Anomaly Detection

Tests whether adding manipulated-variable history to sensor history improves predictive fault detection and early warning under controlled false alarms. It reuses the strongest existing experiment base, while carefully avoiding causal language.

## B — FAVE-TS: Applicability-Aware Retrieval for Industrial Time Series

Tests whether similarity-based historical retrieval can return contextually inapplicable windows and whether explicit applicability checks improve downstream diagnosis. “Similarity != Applicability” is a hypothesis, not an established contribution or novelty claim.
